Zustand + TanStack Query

The most powerful lightweight combo for React & Next.js state management

Zustand (~5.x) + TanStack Query (~5.x) → used in production by thousands of apps

What is Zustand?

Zustand is a tiny (~1–2 KB) global state manager for React.

  • Hook-based → feels exactly like useState
  • No <Provider> needed anywhere
  • One file = one store (easy to split by feature)
  • Perfect TypeScript support
Most new medium/large React apps use Zustand for client/UI state .

What is TanStack Query?

TanStack Query (formerly React Query) is the gold standard for server-state & async data.

  • Automatic fetching, caching, background updates
  • Handles loading/error states, retries, pagination, mutations
  • Declarative → no manual useEffect mess
  • Works perfectly with Next.js App Router
TanStack Query manages server data so well that you almost never need to write custom fetch logic.

Why this combo is extremely strong

  • Separation of concerns: Zustand = client/UI state • TanStack Query = server/async state
  • Minimal boilerplate → write less code, ship faster
  • Insanely performant (no over-fetching, smart caching)
  • Scales from small apps → complex dashboards/SaaS
  • Community favorite: thousands of production apps use exactly this stack
Knowing Zustand + TanStack Query makes you very employable — it's one of the most requested stacks job postings.

When to use this combo?

  • Building dashboards, admin panels, SaaS, internal tools
  • Need global UI state (theme, sidebar, filters, modals...)
  • Fetching/caching/mutating API data frequently
  • Want clean, maintainable code without heavy libraries

Result: You can build any modern dashboard with just these two + React/Next.js.

Example: Theme Toggle with Zustand

// store/theme.store.ts
import { create } from "zustand";

type Theme = "light" | "dark";

type ThemeState = {
    theme: Theme;
    toggleTheme: () => void;
};

export const useThemeStore = create<ThemeState>((set) => ({
    theme: "light",
    toggleTheme: () =>
        set((state) => ({
            theme: state.theme === "light" ? "dark" : "light",
        })),
}));

Using Zustand in Components

// components/ThemeToggle.tsx
import { useThemeStore } from "@/store/theme.store";

export default function ThemeToggle() {
    const theme = useThemeStore((state) => state.theme);
    const toggleTheme = useThemeStore((state) => state.toggleTheme);

    return (
        <button
            onClick={toggleTheme}
            style={{
                background: theme === "dark" ? "#333" : "#f0f0f0",
                color: theme === "dark" ? "white" : "black",
            }}
        >
            Switch to {theme === "dark" ? "Light" : "Dark"} mode
        </button>
    );
}

TanStack Query – Quick Setup in Plain React

// src/main.tsx (or index.tsx) - Wrap your app here
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App.tsx';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';

// Create a client instance (can customize defaultOptions if needed)
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 1000 * 60, // 1 minute - adjust as needed
      gcTime: 1000 * 60 * 5, // 5 minutes garbage collection
    },
  },
});

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <QueryClientProvider client={queryClient}>
      <App />
    </QueryClientProvider>
  </React.StrictMode>
);

// src/components/UserList.tsx - Example component using useQuery
import { useQuery } from '@tanstack/react-query';

async function fetchUsers() {
  const res = await fetch('https://jsonplaceholder.typicode.com/users');
  if (!res.ok) throw new Error('Network response was not ok');
  return res.json();
}

export default function UserList() {
  const { data, isLoading, error } = useQuery({
    queryKey: ['users'],          // Unique key for caching
    queryFn: fetchUsers,          // Fetch function
  });

  if (isLoading) return <p>Loading users...</p>;
  if (error) return <p>Error: {(error as Error).message}</p>;

  return (
    <ul>
      {data?.map((user: any) => (
        <li key={user.id}>{user.name} ({user.email})</li>
      ))}
    </ul>
  );
}

Just drop <UserList /> anywhere in your app — TanStack Query handles fetching, caching, loading & errors automatically!

Best Practices – Zustand + TanStack Query

  • Zustand → client state only (theme, UI toggles, form drafts, filters)
  • TanStack Query → server state only (API data, lists, details, mutations)
  • Use selectors in Zustand for performance
  • One store per feature + one QueryClient per app
This separation keeps your code clean, testable, and blazing fast.
