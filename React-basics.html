1. Props in React (Modern TypeScript 2026)

Props are read-only data passed from parent to child. Type directly on function params for clean, flexible code with excellent generics support.

Key Concepts

  • Props are immutable inside the child.
  • Use `interface` (common for props) or `type`.
  • Default values via JS default parameters (`.defaultProps` removed).
  • Explicit `children: React.ReactNode` when needed.

Modern Code Example: Greeting Component

// Props type
interface GreetingProps {
  name: string;
  age?: number;
}

function Greeting({ name, age = 18 }: GreetingProps) {
  return (
    <p>Hello, {name}! Age: {age}</p>
  );
}

// Usage
<Greeting name={"Alice"} />
<Greeting name={"Bob"} age={30} />

With children (Card example)

import { ReactNode } from 'react';

interface CardProps {
  title: string;
  children: ReactNode;
}

function Card({ title, children }: CardProps) {
  return (
    <div style={{ border: '1px solid #ccc', padding: '1.5rem' }}>
      <h2>{title}</h2>
      {children}
    </div>
  );
}

2. useState Hook

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(prev => prev + 1)}>+1</button>
    </div>
  );
}

3. useEffect Hook

Side effects: fetch, subscriptions, DOM. Dependency array controls timing.

import { useState, useEffect } from 'react';

function UserProfile({ userId }: { userId: string }) {
  const [user, setUser] = useState<any>(null);

  useEffect(() => {
    const fetchUser = async () => {
      const res = await fetch(`/api/user/${userId}`);
      setUser(await res.json());
    };
    fetchUser();

    return () => console.log('cleanup');
  }, [userId]);

  if (!user) return <p>Loading...</p>;

  return <h1>{user.name}</h1>;
}

4. React Router v7

Client-side routing for SPAs. v7 (non-breaking from v6) adds better types, React 19 support, framework bridging.

Setup Steps (Vite + React + TS project)

  1. Install: npm install react-router-dom
  2. Wrap app in BrowserRouter (usually in main.tsx)
  3. Define routes with <Routes> + <Route>
  4. Use <Link> / useNavigate for navigation

Basic Example: Multi-Page Feel

// main.tsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { BrowserRouter } from 'react-router-dom';
import App from './App';

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>
);
// App.tsx — Routes + Navigation
import { Routes, Route, Link } from 'react-router-dom';
import Home from './pages/Home';
import About from './pages/About';
import User from './pages/User';

function App() {
  return (
    <div>
      <nav>
        <Link to="/">Home</Link> | 
        <Link to="/about">About</Link>
      </nav>

      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/user/:id" element={<User />} />
      </Routes>

     </div>
  );
}

export default App;

Dynamic Params + useParams
